# 📚 Amazon Books Analysis

## 📌 About the Project
This project focuses on analyzing Amazon bestselling books using Python.
The goal is to explore book ratings, prices, genres, and popularity
to discover useful insights from the dataset.

## 🎯 Project Objectives
- Identify the top 10 bestselling books.
- Analyze book ratings.
- Compare book prices.
- Discover popular book genres.
- Identify highly rated authors.
- Visualize data using graphs and charts.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Key Features
- Data cleaning and preprocessing.
- Exploratory Data Analysis (EDA).
- Statistical analysis.
- Data visualization.
